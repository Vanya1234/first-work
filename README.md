# Сбор информации о системе на Python

Учебный проект для сбора сведений о системе в Windows и macOS без выполнения команд терминала. Данные получаются с помощью функций Python и сохраняются в файл `system_info.json`.

В проекте представлены две версии программы:

- **С использованием `psutil`** — собирает основные сведения о системе, данные об оперативной памяти и информацию о процессах.
- **Без `psutil`** — собирает основные сведения о системе, используя только стандартную библиотеку Python.

## Цель проекта

Изучить способы получения системной информации средствами Python и сравнить возможности стандартной библиотеки с возможностями сторонней библиотеки `psutil`.

## Возможности

| Собираемые данные | С `psutil` | Без `psutil` |
|---|:---:|:---:|
| Название и версия операционной системы | ✓ | ✓ |
| Имя компьютера и пользователя | ✓ | ✓ |
| Сведения о процессоре | ✓ | ✓ |
| Количество логических процессоров | ✓ | ✓ |
| IP-адрес, полученный по имени компьютера | ✓ | ✓ |
| Дата и время сбора данных | ✓ | ✓ |
| Путь к интерпретатору Python | ✓ | ✓ |
| Общий, используемый и свободный объём оперативной памяти | ✓ | — |
| Сведения о процессах | ✓ | — |

Версия с `psutil` отбирает процессы со статусом `running`, для которых доступны сведения о памяти, сортирует их по объёму занятой физической памяти (RSS) и записывает первые десять.

Для каждого выбранного процесса сохраняются:

- идентификатор — PID;
- название;
- статус;
- объём занятой физической памяти;
- дата и время запуска.

## Используемые библиотеки

- `platform` — сведения об операционной системе и процессоре.
- `os` — имя пользователя из переменных окружения и количество логических процессоров.
- `socket` — имя компьютера и получение IP-адреса по этому имени.
- `sys` — путь к интерпретатору Python.
- `datetime` — дата и время.
- `json` — сохранение результатов.
- `psutil` — оперативная память и процессы в расширенной версии.

Все перечисленные модули, кроме `psutil`, входят в стандартную библиотеку Python.

## Запуск

1. Установите Python 3.
2. Сохраните код выбранной версии в файл с расширением `.py`.
3. Откройте файл в среде разработки, например IDLE или PyCharm.
4. Для расширенной версии установите `psutil` в используемое окружение Python. Это можно сделать через менеджер пакетов вашей среды разработки.
5. Запустите программу кнопкой запуска в среде разработки.

После успешного выполнения в текущей рабочей папке появится файл `system_info.json`. Текущая рабочая папка определяется настройками запуска и может отличаться от папки со скриптом.

Обе версии используют одинаковое имя выходного файла. При повторном запуске его содержимое перезаписывается.

## Формат результата

Результат сохраняется в JSON с отступами и кодировкой UTF-8.

| Поле | Содержание |
|---|---|
| `OC` | Название операционной системы |
| `version_OS` | Релиз операционной системы |
| `Name_computer` | Имя компьютера |
| `Username` | Имя пользователя |
| `CPU_architecture` | Значение, возвращаемое `platform.processor()` |
| `count_cores` | Количество логических процессоров |
| `ip_pc` | IPv4-адрес, полученный по имени компьютера |
| `Time` | Дата и время сбора данных |
| `Python_path` | Путь к интерпретатору Python |
| `RAM` | Общий объём оперативной памяти — только с `psutil` |
| `RAM_used` | Используемая оперативная память — только с `psutil` |
| `RAM_free` | Свободная оперативная память — только с `psutil` |
| `process_1` … `process_10` | Сведения о выбранных процессах — только с `psutil` |

Объёмы памяти указываются в мебибайтах (МиБ): количество байтов делится на `2²⁰`. Дата и время записываются в формате `ДД.ММ.ГГГГ ЧЧ:ММ:СС`.

## Особенности текущей реализации

- Несмотря на название поля `CPU_architecture`, в него записывается результат `platform.processor()`.
- Поле `count_cores` отражает количество логических процессоров, а не физических ядер.
- Список процессов ограничен статусом `running`, поэтому это не десять самых затратных по памяти процессов среди всех существующих процессов.
- Расширенная версия предполагает наличие хотя бы десяти подходящих процессов. Если их меньше, программа завершится с ошибкой.
- Если время создания процесса недоступно, его преобразование в дату также может вызвать ошибку.
- Получение IP-адреса зависит от разрешения имени компьютера. При ошибке определения адреса выполнение прерывается.
- Состав доступных сведений может различаться между Windows и macOS. Показатель свободной памяти `RAM_free` не равнозначен памяти, доступной для запуска новых приложений.

## Итог

Стандартная библиотека Python позволяет получить основные сведения о системе без сторонних зависимостей. Использование `psutil` расширяет возможности программы: добавляет данные об оперативной памяти и работающих процессах.
